Outputs

Build named output commands from local sensors or imported CAN signals. Binary state/valid/pulse is broadcast on CAN base + 5; PWM duty is paired on CAN base + 6.

The first matching case wins. Tests inside one case are ANDed; additional cases provide ELSE-IF/OR behavior. IF/AND tests select the case; PULSE and PWM lookup tables then determine pulse timing or duty rather than forcing the state bit ON. A Triggered timer can latch a false → true sensor/CAN condition for a configured period, including after its trigger CAN source disappears. Missing or stale data required by ordinary source tests forces the output safely OFF.

Select a reference DBC to populate CAN message and signal choices in Conditions, Output tests and Triggered timers.

Conditions

Define a named true/false condition once and reuse it in multiple Output cases or Triggered timers. Stale behavior is applied only after the source has produced at least one valid sample.
